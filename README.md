# Legal Syntax Lab

面向英文法律长句的交互式句法分析工具。用户可以粘贴英文句子，通过 Gemini 生成结构化分析，并利用分句着色、特征语法词提示、同步中文讲解和拖拽重组理解复杂句式。

## 主要功能

- 英文法律句法结构分析
- 条件、主句、但书、例外、修饰语和范围限制着色
- 特征语法词加粗与下划线提示
- 阅读、语序重组和结构归位练习
- 成功分析历史记录与一致性状态
- 多选导出带结构着色的 Word 文档
- 用户可编辑分析要求，系统锁定 JSON 数据协议
- request_id、原文指纹、独立 token 前缀和 surface_text 错配防护

## 本机运行

运行：

```text
start-legal-syntax-lab.bat
```

然后访问：

```text
http://127.0.0.1:8765/legal-syntax-lab.html
```

本机代理会在运行时读取已有的 Gemini 配置。API Key 不存放在网页、浏览器存储或本仓库中。

## 数据安全

- `.env`、实验输出和本机测试产物不会提交。
- 历史分析保存在浏览器 IndexedDB 中。
- 本机 API 代理仅监听 `127.0.0.1`。
