# 后端模块清单

| 目录 | 职责 |
|---|---|
| `src/db/` | SQLite 连接、迁移、备份与事务基础设施 |
| `src/auth/` | 密码、Session、登录和角色授权 |
| `src/modules/` | 用户、教学项目、Prompt、译文版本与活动业务模块 |
| `src/ops/` | 管理员初始化、恢复和数据运维命令 |
| `src/seed/` | 现有 Demo 项目的系统模板幂等导入 |
| `tests/` | 迁移、权限、版本追溯与恢复集成测试 |

后端采用单 SQLite 数据库。用户隔离由统一授权服务和 Repository 查询范围实现；路由不得直接绕过授权层查询跨用户数据。
